# Šablona Bug Reportu – Login Form QA

## 1. Účel dokumentu

Tato šablona slouží k zaznamenávání chyb nalezených během provádění testů aplikace Login Form QA.

Konkrétní bug report bude vytvořen pouze v případě, že skutečný výsledek testu nebude odpovídat očekávanému výsledku.

## 2. Závažnost chyby

| Závažnost | Význam |
| --- | --- |
| Critical | Aplikaci nebo její hlavní funkci nelze používat. |
| High | Důležitá funkce nefunguje a neexistuje vhodné náhradní řešení. |
| Medium | Funkce nefunguje správně, ale existuje náhradní postup. |
| Low | Drobná nebo převážně vizuální chyba. |

## 3. Priorita opravy

| Priorita | Význam |
| --- | --- |
| Vysoká | Chybu je potřeba opravit co nejdříve. |
| Střední | Chyba má být opravena, ale neblokuje hlavní používání aplikace. |
| Nízká | Opravu lze naplánovat na pozdější dobu. |

## 4. Šablona bug reportu

| Položka | Hodnota |
| --- | --- |
| Bug ID | BUG-XXX |
| Název chyby | Doplnit stručný a jednoznačný název |
| Související test case | TC-XXX |
| Související požadavek | FR-XXX nebo NFR-XXX |
| Prostředí | Prohlížeč, operační systém, zařízení |
| Závažnost | Critical / High / Medium / Low |
| Priorita | Vysoká / Střední / Nízká |
| Stav | New |
| Četnost výskytu | Například 3 z 3 pokusů |
| Datum nalezení | RRRR-MM-DD |

Tento dokument je pouze šablona. Neobsahuje skutečně nalezenou chybu.
